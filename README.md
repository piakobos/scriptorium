# Scriptorium

A desktop Bible study reader for Windows and macOS, with dictionaries, morphology, commentary and personal notes.

## Downloads

Open this repository's **Releases** page and download:

- **Windows:** `Scriptorium Setup.exe` — run the installer. Microsoft Edge WebView2 Runtime is required.
- **Mac:** `Scriptorium Mac.zip` — extract the whole ZIP, then move `Scriptorium.app` to Applications. Includes Intel and Apple silicon runtimes; requires macOS 11 or later. The ZIP also includes startup-log and browser-launch helpers.

The Mac package is unsigned. Its contents and dependencies have been checked on Windows; native Mac execution has not yet been verified.

`SHA256SUMS.txt` accompanies each release for checking the downloads.
