# Scriptorium

A desktop Bible study reader for Windows, macOS and Linux, with dictionaries, commentary and personal notes.

## Downloads

Open this repository's **Releases** page and choose the download for your computer:

- **Windows:** `Scriptorium Setup.exe`
- **Mac:** `Scriptorium Mac.zip`
- **Linux:** `Scriptorium Linux.tar.gz`

Included texts retain their original licences and restrictions; see Sources & help in the app and its bundled credits.

## Preparing a release

The local `release-assets` folder contains only these three application packages. See `UPLOAD INSTRUCTIONS.txt` for the upload procedure. Source/import archives, reports, checksums and release notes stay in the master project's Delivery or Preserved history folders.
